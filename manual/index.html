1. 앱과 데이터 이해하기

무엇을 관리하는 앱인가요?

알림온나는 식품, 생활용품, 소모품 등의 구매일·만료일과 보유 수량을 관리하는 앱입니다. 기한이 가까워진 물건을 확인하고, 필요한 물건은 쇼핑 리스트에 적어 두며, 구매한 기록을 따로 보관할 수 있습니다.

이 설명서는 한국어 화면의 기본 명칭을 사용합니다. 날짜 라벨을 바꾼 경우 ‘구매일’, ‘만료일’은 직접 지정한 이름으로 표시됩니다. 예를 들어 구매일을 ‘등록일’, 만료일을 ‘교체일’로 바꾸어 생활용품 교체 주기를 관리할 수 있습니다.

세 가지 목록의 역할

메인 목록, 쇼핑 리스트, 구매 내역의 차이
메인 목록 · 관리대상현재 관리하는 물건을 보관합니다. 분류, 구매일, 만료일, 수량, 알림, 태그, 이미지 등을 사용합니다.
쇼핑 리스트구매할 물건과 구매 완료 상태를 그룹별로 정리합니다. 구매처·가격·항목별 메모를 기록하고, 구매한 물건을 관리대상으로 등록할 수 있습니다.
구매 내역언제, 어디서, 무엇을 얼마에 샀는지 기록합니다. 메인 목록의 수량이나 쇼핑의 구매 스위치를 바꾸는 것과 별도로 저장하는 기록입니다.

목록 사이의 등록은 새 항목을 만드는 작업입니다. 쇼핑리스트로 보내기나 관리대상 등록을 해도 원래 항목은 남습니다. 같은 작업을 다시 하면 항목이 추가될 수 있으므로 결과를 확인하세요.

저장과 연결

일반적인 등록·조회·편집은 기기에 저장된 데이터를 사용합니다. Google Drive는 백업 파일을 보관하는 용도이며, 다른 기기나 가족의 앱과 변경 내용을 실시간으로 맞추는 기능은 아닙니다. AI 기능과 Google Drive 이용에는 인터넷 연결이 필요합니다.

설정에 따라 이미지나 태그 입력 영역이 숨겨질 수 있습니다. 화면에 요소가 보이지 않으면 표시 옵션을 먼저 확인하세요.

2. 빠른 시작

첫 품목 등록하기

  1. 메인 화면의 메뉴를 열고 환경설정 → 분류 및 이미지 관리 → 분류 설정에서 사용할 분류를 준비합니다. 이미 분류가 있으면 그대로 사용합니다.
  2. 메인 화면 위쪽의 +를 누릅니다.
  3. 분류와 항목명을 입력하고 구매일·만료일을 지정합니다. 예: 냉장식품 / 우유 / 구매일 2026.09.12 / 만료일 2026.09.19.
  4. 수량에 2팩을 입력하고, 필요하면 가격·메모·태그·사진을 추가합니다.
  5. 항목의 알림 사용 여부와 며칠 전부터 알릴지 확인한 뒤 저장을 누릅니다.
  6. 환경설정 → 알림 관리에서 앱 전체의 알림 서비스를 켜고 알림 시각과 기기 알림 권한을 확인합니다.

일상에서 사용하는 순서

  1. 등록물건의 날짜와 수량을 입력합니다.
  2. 확인알림 대상이나 달력에서 가까운 기한을 확인합니다.
  3. 소비수량을 줄이고, 다 썼으면 0으로 기록합니다.
  4. 장보기다시 살 물건을 쇼핑 리스트에 추가합니다.

장보기가 끝나면 구매 완료로 바꾸고, 필요에 따라 구매내역에 저장하거나 관리대상에 등록합니다. 중요한 자료가 쌓였다면 백업도 만들어 두세요.

3. 메인 목록과 조작

메뉴와 기본 필터

왼쪽 메뉴에서 전체 보기, 알림 대상, 기한 만료, 소비 완료 또는 특정 분류·태그를 선택합니다. 쇼핑 리스트, 구매 내역, 달력으로 보기, 환경설정도 이 메뉴에서 엽니다. 넓은 화면에서는 메뉴가 본문 옆에 표시될 수 있습니다.

기본 필터에 표시되는 항목
전체 보기현재 등록된 관리대상을 표시합니다. 수량이 0인 항목도 포함됩니다.
알림 대상항목별 알림이 켜져 있고, 오늘부터 만료일까지의 남은 기간이 해당 항목의 알림일 이내인 항목입니다.
기한 만료만료일이 오늘보다 이전인 항목입니다. 오늘 만료되는 항목은 ‘오늘’ 상태로 구분됩니다.
소비 완료수량을 0으로 기록한 항목입니다. 수량을 비워 둔 항목은 소비 완료로 보지 않습니다.
분류·태그해당 분류에 속하거나 선택한 태그가 연결된 항목을 표시합니다.

탭, 길게 누르기, 스와이프

  • 항목 탭: 편집 화면을 엽니다. 이미지는 이미지 영역을 눌러 확인할 수 있습니다.
  • D-day 배지 탭: 구매일에서 만료일까지의 진행 상태를 확인합니다.
  • 항목 길게 누르기 또는 선택 메뉴: 여러 항목을 선택하는 모드로 들어갑니다.
  • 항목을 오른쪽으로 밀기: 쇼핑리스트에 추가합니다. 대상 쇼핑 그룹을 선택하거나 새 그룹을 만듭니다.
  • 항목을 왼쪽으로 밀기: 삭제 확인 후 항목을 삭제합니다.

여러 항목을 한 번에 처리하기

선택 모드에서 항목을 체크하거나 전체선택을 사용합니다. 선택한 항목을 쇼핑 리스트에 추가하거나, 다른 분류로 옮기거나, 삭제할 수 있습니다. 작업 전에 현재 필터와 선택 건수를 확인하세요. 전체선택은 현재 목록에 표시된 범위를 기준으로 사용합니다.

정렬과 가독성

정렬 순서에서 입력 순, 항목명 순, 구매일 순, 만료일 순과 역순 여부를 정합니다. 여러 분류를 함께 볼 때는 분류 순서가 먼저 적용되고, 각 분류 안에서 지정한 순서로 정렬됩니다.

목록에서 두 손가락을 벌리거나 모으면 글자 배율을 조절할 수 있습니다. 메인 목록 배율은 90~130%이며, 환경설정 → 화면 및 테마 설정 → 폰트 크기에서도 조절합니다. 줄간격은 별도 옵션입니다.

4. 검색과 상세 조건

검색어로 찾기

메인 화면의 검색 버튼을 눌러 검색 화면을 엽니다. 항목명뿐 아니라 메모, 분류명, 연결된 태그명도 검색합니다. 영문 대소문자는 구분하지 않으며, 한국어 초성 검색도 지원합니다. 예를 들어 ㅇㅇ로 ‘우유’를 찾을 수 있습니다.

검색어를 공백으로 나누어 입력하면 각 단어를 모두 포함하는 항목을 찾습니다. 단어가 서로 다른 필드에 있어도 됩니다. 예: 우유 냉장은 이름에 ‘우유’, 분류나 메모에 ‘냉장’이 있는 항목을 찾는 데 쓸 수 있습니다.

상태·날짜·수량 조건 조합하기

상세 검색 조건
상태주의, 경고, 오늘, 만료, 기한없음 중 필요한 상태를 선택합니다. 여러 상태를 고르면 그중 하나에 해당하는 항목이 검색됩니다. 주의·경고 기준은 배지 상태 조건을 따릅니다.
날짜 기준구매일 또는 만료일을 고른 후 오늘, 3일 이내, 7일 이내, 특정일, 기간을 설정합니다.
3일·7일 이내구매일 기준은 오늘부터 과거 방향, 만료일 기준은 오늘부터 미래 방향입니다. 예: 9월 12일에 3일 이내로 검색하면 구매일은 9월 9~12일, 만료일은 9월 12~15일입니다.
특정일·기간달력에서 날짜를 고르거나 시작일·종료일로 범위를 정합니다. 양 끝 날짜도 포함됩니다. 기한없는 항목은 만료일 날짜 검색에 포함되지 않습니다.
수량0, 1 이하, 3 이하 또는 직접 입력한 최대 수량으로 검색합니다. 수량이 비어 있는 항목은 수량 조건 검색에서 제외됩니다.

검색어·상태·날짜·수량을 함께 사용하면 각 조건을 모두 만족하는 항목을 찾습니다. 원하는 조건을 설정한 뒤 적용을 누릅니다. 결과가 없으면 조건을 줄이거나 초기화하고, 현재 분류나 목록 필터도 확인하세요.

5. 품목 등록과 편집

입력 항목 설명

메인 품목의 입력 정보
분류 · 필수물건을 정리할 분류를 선택합니다. 필요한 분류는 분류 설정에서 만듭니다.
항목명 · 필수목록과 검색에 사용할 이름입니다. 비슷한 제품을 구분할 수 있도록 제품명이나 규격을 함께 적으면 편리합니다.
구매일 · 필수구매하거나 관리하기 시작한 날짜입니다. 달력의 구매일 보기와 기간 진행률에 사용됩니다.
만료일 · 필수사용·소비·교체 등의 기준 날짜입니다. D-day, 달력, 기한 알림의 기준입니다.
수량(단위)2개, 1.5L처럼 보유량을 입력합니다. 0은 소비 완료로 분류됩니다. 내용량을 함께 입력할 수도 있습니다.
가격기록할 금액을 입력합니다. 수량과 함께 사용하면 단위가격을 참고할 수 있습니다.
태그 · 메모태그는 여러 특징을 붙여 찾는 데 사용하고, 메모에는 보관 위치나 사용 방법 등을 자유롭게 기록합니다.
이미지제품 사진이나 바코드 등을 붙입니다. 이미지 사용 설정에 따라 입력 영역이 표시됩니다.
알림 설정이 항목의 알림 사용 여부와 만료 며칠 전부터 알릴지 정합니다. 신규 항목은 환경설정의 기본 알림값을 가져옵니다.

저장·초기화·복제

  • 신규 등록: 입력을 마친 뒤 저장합니다. 필수값이 비어 있거나 날짜가 올바르지 않으면 해당 입력란을 수정해야 합니다.
  • 수정: 기존 항목을 열고 원하는 값을 바꾼 뒤 저장합니다.
  • 초기화: 신규 등록이나 복제 화면에서 작성 중인 입력값을 초기화합니다.
  • 복제하기: 기존 품목을 바탕으로 새 항목을 작성합니다. 날짜·수량 등을 확인하고 저장하면 별도 항목으로 등록됩니다.
  • 쇼핑리스트에 추가: 기존 항목의 편집 화면에서 사용할 수 있습니다. 대상 그룹을 선택하면 이미 저장된 값으로 쇼핑 항목을 만듭니다. 수정한 값을 보내려면 먼저 저장하세요.

자동저장과 연속 수정의 차이

자동저장은 기존 항목을 수정할 때 변경된 값을 저장하는 옵션입니다. 메인리스트, 쇼핑리스트, 구매내역별로 따로 켭니다. 글자 입력을 잠시 멈추거나 값을 변경했을 때 필수값과 날짜가 유효하면 저장되며, 저장 표시를 확인할 수 있습니다.

신규 등록과 복제는 직접 저장해야 합니다. 자동저장을 켜도 필수 정보가 빠진 상태까지 저장되지는 않습니다. 자동저장이 꺼져 있다면 편집 화면에서 나가거나 다음 항목으로 이동하기 전에 저장하세요.

연속 수정 모드는 메인 목록에서 여러 항목을 편집할 때 화면 아래쪽 입력란 아래의 여백을 좌우로 밀어 이전·다음 항목으로 이동하는 기능입니다. 위쪽의 현재 위치/전체 건수로 이동 상태를 확인합니다. 이 옵션 자체가 저장을 대신하지는 않으며, 쇼핑리스트나 구매내역에는 적용되지 않습니다.

기한없는 항목

만료일의 연도가 9999년인 항목은 ‘기한없음’으로 표시됩니다. 예를 들어 날짜 형식이 연·월·일, 구분자가 점이면 9999.12.31로 입력합니다. 빈 날짜와는 다르며, 만료일 기준 날짜 검색이나 기한 알림 대상에 들어가지 않습니다.

6. 빠른 입력·수량·가격·날짜

메인 품목의 빠른 입력

빠른 입력 창에서 여러 값을 한 줄로 적고 추출 결과를 확인한 뒤 적용합니다. 적용은 입력란을 채우는 작업이며, 신규 항목은 이어서 저장해야 합니다. 입력 규칙은 창 안의 안내 버튼에서도 확인할 수 있습니다.

우유 2팩 4500원 9.12 9.19 냉장보관
항목명 우유 · 수량 2팩 · 가격 4500 · 구매일 9월 12일 · 만료일 9월 19일 · 메모 냉장보관

  • 기본 순서: 항목명 → 수량 → 가격 → 날짜 → 메모.
  • 2000원은 가격, 3팩은 수량으로 우선 해석합니다.
  • 단독 숫자 하나는 가격을 우선으로, 단독 숫자 두 개는 앞을 수량·뒤를 가격으로 해석합니다.
  • 날짜가 하나면 만료일에 적용합니다. 둘 이상이면 앞의 두 날짜 중 빠른 날짜를 구매일, 늦은 날짜를 만료일로 적용합니다.
  • 마지막 날짜 뒤의 텍스트는 메모로 처리합니다. 날짜는 현재 날짜 형식 설정을 기준으로 인식하며 9.12 같은 짧은 입력도 지원합니다.

인라인 빠른 입력을 켜면 신규 등록 화면의 항목명 입력 아래에 해석된 결과가 제안됩니다. 제안을 확인하고 적용하세요. 제품명에 숫자가 많거나 규칙이 섞인 경우에는 추출 결과를 먼저 확인하는 것이 좋습니다.

쇼핑리스트의 빠른 입력

쇼핑 그룹을 선택하고 빠른 입력을 엽니다. 항목명 [수량] [내용량] [가격] 형태로 입력한 뒤 추가합니다. 이 창의 추가 버튼은 실제 쇼핑 항목을 등록하므로 같은 내용을 반복 추가하지 않도록 결과를 확인하세요.

콜라 6캔 355ml 4800원
수량 6캔 · 한 캔의 내용량 355ml · 전체 가격 4800원

숫자와 단위를 붙여 쓰면 수량과 내용량을 구분하기 쉽습니다. 앞의 숫자+단위는 수량, 다음 숫자+단위는 내용량으로 해석합니다.

수량, 단위, 내용량

수량 입력 예시
3팩기본 수량 3, 단위 팩. 보유량을 바꿀 때 수량을 수정합니다.
1.5L소수 수량도 입력할 수 있습니다.
6캔 355ml6캔을 보유하고 한 캔의 내용량은 355ml라는 뜻입니다. 내용량은 단위가격 계산을 돕는 보조 정보입니다.
숫자만 수정입력한 단위를 유지하면서 수량을 바꿀 수 있습니다. 단위를 바꾸려면 2병처럼 새 단위를 함께 적습니다.
− / + 버튼수량을 인식할 수 있을 때 증감합니다. 정수는 1, 소수는 0.1 단위로 조절하며 0 아래로 줄이지 않습니다.

가격, 단위가격, 계산기

단위가격을 비교하려면 가격칸에 해당 수량의 전체 금액을 입력합니다. 예를 들어 6캔에 4800원이면 1캔당 800원입니다. 내용량도 있으면 전체 내용량을 기준으로 한 단위가격이 함께 표시됩니다. 미리보기의 기준 단위와 반올림된 표시값을 확인하세요.

쇼핑 등록·편집 화면의 가격 입력 ×(곱하기) 기능은 수량과 현재 가격을 곱해 가격칸에 반영합니다. 개당 가격을 입력한 경우 전체 금액으로 바꾸는 데 사용합니다. 이미 전체 금액을 적었다면 다시 곱할 필요가 없습니다.

가격 입력용 키보드의 계산기를 사용하면 수식을 계산하고 가격으로 보내기로 결과를 적용할 수 있습니다. 금액 표시는 앱 언어의 로케일 영향을 받으므로 한국어와 영어에서 소수점·자릿수 표시가 다를 수 있습니다.

날짜 입력과 확인

날짜를 직접 입력하거나 달력 아이콘으로 선택합니다. 날짜 선택 창은 확인 버튼으로 확정할 수 있고, 날짜를 빠르게 두 번 누르는 방식도 지원합니다. 짧은 입력의 자동 완성·제안을 사용할 때는 완성된 연도까지 확인하세요.

환경설정 → 날짜 및 동작 설정에서 연·월·일 순서와 구분자를 바꿉니다. 날짜 논리 체크를 켜면 만료일이 구매일보다 이전인 입력에 오류를 표시합니다. 같은 날짜는 사용할 수 있습니다.

7. 이미지와 이미지 저장소

항목에 이미지 붙이기

항목의 이미지 영역을 누르면 현재 상태에 맞는 메뉴가 표시됩니다. 사진 촬영, 갤러리에서 선택, 이미지 저장소에서 선택, 등록된 이미지에서 선택, 바코드 생성 등을 사용할 수 있습니다. 촬영·갤러리 선택 후에는 필요한 부분을 자르거나 회전하고 적용합니다.

이미지를 누르면 크게 볼 수 있습니다. 미리보기에서는 확대·이동으로 내용을 확인합니다. 사용 가능한 메뉴에서 이미지 저장소에 저장하거나 해당 이미지를 삭제할 수 있습니다.

자주 쓰는 이미지 저장소

환경설정 → 분류 및 이미지 관리 → 이미지 저장소

  1. +에서 사진을 촬영하거나 갤러리에서 고릅니다.
  2. 이미지를 자르고 해상도·품질을 확인합니다. 검색하기 쉬운 이미지명을 지정할 수 있습니다.
  3. 저장소에서 이미지명으로 검색하고, 이미지 이름을 변경하거나 개별·다중 선택으로 삭제할 수 있습니다.
  4. 항목에 사용할 때는 항목 이미지 메뉴에서 이미지 저장소에서 선택을 누릅니다.

이미지 저장소는 자주 쓰는 사진을 보관하는 곳입니다. 저장소에서 사진을 삭제해도 이미 항목에 가져다 쓴 이미지는 남습니다.

이미지 해상도와 품질

환경설정 → 분류 및 이미지 관리에서 이미지 해상도와 품질을 선택합니다.

  • 해상도: 저장할 사진의 크기를 정합니다. 높은 해상도는 사진을 크게 볼 때 유리하고, 낮은 해상도는 저장 공간을 아끼는 데 도움이 됩니다.
  • 품질: 사진 화질과 파일 용량의 균형을 정합니다. 선명함이 중요하면 ‘품질 우선’, 용량을 줄이고 싶으면 ‘용량 우선’을 선택하세요.

이미지 표시 옵션

환경설정 → 화면 및 테마 설정 → 이미지 사용에서 메인리스트와 쇼핑리스트를 따로 체크합니다. 이 옵션은 이미지 요소의 표시 여부를 정합니다. 체크를 해제하는 것만으로 등록된 이미지가 삭제되지는 않으며, 두 목록의 체크 상태가 달라도 목록 간 등록 시 이미지는 함께 전달됩니다.

바코드와 등록된 이미지

바코드 생성에서 Code128 또는 QR Code를 고르고 내용을 입력한 뒤 생성 및 적용합니다. 바코드 유형이 지원하지 않는 문자는 수정해야 합니다. 생성된 코드는 항목 이미지로 사용할 수 있습니다.

등록된 이미지에서 선택은 이미 앱에 등록된 이미지 중에서 고르는 기능입니다. 자주 쓰는 사진을 따로 이름 붙여 보관하고 싶다면 이미지 저장소를 이용하세요.

8. 분류·태그·그룹

어떤 기준으로 나누면 좋을까요?

분류와 그룹, 태그의 용도
분류메인 품목 하나가 속하는 기본 위치입니다. 예: 냉장식품, 냉동식품, 욕실용품.
분류의 그룹여러 분류를 메뉴에서 묶는 상위 구분입니다. 예: ‘주방’ 그룹 아래 냉장식품·냉동식품.
태그분류를 넘어 여러 특징을 붙입니다. 예: 아침, 개봉함, 먼저 사용. 한 항목에 여러 태그를 붙일 수 있습니다.
쇼핑리스트 그룹장보기 목록을 나누는 단위입니다. 예: 마트, 온라인, 이번 주. 메인 분류의 그룹과 별도로 관리합니다.

분류와 상위 그룹 관리

환경설정 → 분류 및 이미지 관리 → 분류 설정

분류와 그룹을 추가하고 이름을 바꾸며, 순서 변경 조작으로 표시 순서를 정합니다. 분류 편집에서 소속 그룹을 바꿀 수 있습니다. ‘미지정’ 영역은 상위 그룹이 정해지지 않은 분류를 모아 보여 줍니다.

메인 화면의 드로어에서 분류 그룹 제목을 누르면 하위 분류를 접거나 펼칩니다. 현재 선택된 분류가 속한 그룹도 접을 수 있으며, 접더라도 선택된 분류와 표시 중인 품목 목록은 그대로 유지됩니다.

상위 그룹만 삭제하면 그 안의 분류는 그룹 미지정 상태로 남습니다. 반면 분류 삭제는 해당 분류의 항목 삭제를 포함하므로 확인 창의 건수를 확인하세요. 물건을 남기려면 메인 목록에서 다른 분류로 먼저 옮깁니다.

태그 입력과 관리

  • 항목 편집 화면에서 태그명을 입력하면 기존 태그 제안이 표시됩니다. 원하는 제안을 눌러 추가합니다.
  • 새 태그는 이름을 입력하고 공백을 눌러 추가합니다. 같은 태그는 중복으로 붙지 않습니다.
  • 태그 칩의 ×는 그 항목에서 태그를 떼어냅니다. 입력칸의 …에서 여러 태그를 선택·해제할 수 있습니다.
  • 태그 설정에서는 태그 추가·이름 변경·정렬·삭제와 배경색·폰트색을 설정합니다. 색상 창의 미리보기와 밝고 어두운 배경을 이용해 가독성을 확인하세요.

태그 설정에서 태그 자체를 삭제하면 연결된 항목에서 그 태그가 제거됩니다. 물건 자체를 삭제하는 작업은 아닙니다. 태그 사용 옵션을 끄는 것은 태그 관련 화면 요소를 숨기는 설정입니다.

쇼핑 그룹 관리

쇼핑리스트 그룹 설정에서 그룹을 추가하고 이름과 순서를 바꿉니다. 쇼핑 화면에서도 그룹을 추가할 수 있습니다. 항목이 있는 그룹을 삭제하면 그 그룹의 쇼핑 항목도 삭제되므로, 필요한 항목은 다른 그룹으로 먼저 옮겨 주세요.

9. 달력으로 보기

월 이동과 날짜 기준

메뉴에서 달력으로 보기를 엽니다. 달력 영역을 좌우로 스와이프해 이전·다음 달로 이동합니다. 위쪽의 연·월 제목을 누르면 연도를 선택할 수 있고, 다른 달을 보는 중에 표시되는 오늘을 누르면 현재 달로 돌아옵니다.

위쪽의 보기 모드 전환 버튼으로 만료일 기준과 구매일 기준을 바꿉니다. 만료일 기준은 언제까지 사용해야 하는지, 구매일 기준은 언제 구입했는지 살펴볼 때 사용합니다.

달력 높이와 날짜별 목록

달력과 아래 목록 사이의 구분선을 위아래로 끌어 달력 높이를 조절합니다. 달력이 작으면 날짜를 선택해 아래 목록에서 품목을 확인하고, 달력을 크게 펼친 상태에서는 항목이 있는 날짜를 눌러 날짜별 상세 화면으로 이동합니다. 표시 공간을 넘는 항목은 건수 표시와 상세 목록에서 확인하세요.

날짜별 목록에서도 품목을 눌러 편집하고 이미지를 확인할 수 있습니다. 화면의 날짜 색과 상태 색은 선택한 테마를 따릅니다.

달력 글자와 요일 설정

  • 달력 위쪽 폰트 크기 버튼: 달력 항목 글자 배율을 100~130%로 조절합니다.
  • 환경설정 → 화면 및 테마 설정 → 달력 폰트 크기: 날짜와 항목명 각각의 최소·최대 크기를 정합니다. 미리보기로 비교할 수 있으며, 선택 범위는 6~16입니다.
  • 달력 시작 요일: 한 주의 첫 요일을 선택합니다. 홈 화면 위젯의 요일 순서에도 적용됩니다.
  • 달력 요일 영어 사용: 앱 언어와 관계없이 달력과 위젯의 요일을 영어로 표시합니다.

좁은 화면에서 항목명이 잘리면 글자 크기뿐 아니라 달력 높이도 함께 조절해 보세요. 달력 화면의 배율과 환경설정의 최소·최대 크기는 서로 다른 설정입니다.

10. 쇼핑 리스트

그룹 선택과 항목 추가

쇼핑 리스트를 열고 아래쪽에서 작업할 그룹을 선택합니다. 그룹이 없으면 그룹 추가로 만듭니다. +에서 직접 입력하거나 빠른 입력으로 항목을 추가할 수 있습니다. 메인 품목을 쇼핑리스트로 보내는 방법도 있습니다.

등록·편집 화면에서는 그룹, 항목명, 수량과 내용량, 가격, 구매일, 구매처, 메모, 이미지, 구매 완료 여부를 설정합니다. 신규 입력 중 항목명을 타이핑하면 구매내역을 바탕으로 제안이 표시되며, 선택하면 관련 정보를 빠르게 채울 수 있습니다.

같은 곳에서 산 물건을 연속 등록할 때는 신규 화면의 구매처 반복 입력을 사용합니다. 반복 상태를 확인하고, 다음에 다른 구매처의 물건을 입력할 때는 값을 바꾸거나 반복을 해제하세요.

선택 체크와 구매 완료 스위치

비슷해 보이지만 역할이 다른 두 조작
선택 체크박스일괄 작업할 대상을 지정합니다. 체크만으로 구매 완료가 되거나 구매내역이 추가되지 않습니다. 위쪽 전체선택은 현재 그룹의 항목을 대상으로 합니다.
구매 완료 스위치실제로 구매했는지 표시합니다. 켜면 구매완료, 끄면 구매대상입니다.
구매일 자동 변경옵션이 켜져 있으면 구매대상에서 구매완료로 바뀔 때 구매일을 오늘로 변경합니다. 구매 완료를 해제한다고 이전 구매일로 되돌리지는 않습니다.

구매 완료 표시는 쇼핑 항목의 상태입니다. 구매내역 보관이나 메인 관리대상 등록은 아래의 별도 메뉴로 실행합니다.

리스트 모드와 일괄 작업

일반 리스트에서는 항목을 눌러 편집하고, 순서 변경 조작으로 나열 순서를 바꿉니다. 항목을 오른쪽으로 밀면 관리대상 등록, 왼쪽으로 밀면 삭제를 진행할 수 있습니다.

선택한 쇼핑 항목에 적용하는 메뉴
그룹 이동선택 항목을 다른 쇼핑 그룹으로 옮깁니다.
구매일 변경선택 항목의 구매일을 지정한 날짜로 맞춥니다.
구매처 변경선택 항목의 구매처를 한 번에 바꿉니다.
구매내역에 저장선택 항목을 구매 내역으로 기록합니다. 구매일은 저장한 오늘 날짜로 기록됩니다. 구매 완료 여부와 선택 여부는 별개이므로 저장할 대상을 확인하세요.
클립보드에 복사선택한 항목 정보를 텍스트로 복사합니다. 다른 앱의 메시지나 메모에 직접 붙여 넣을 수 있습니다.
선택 삭제선택한 쇼핑 항목을 삭제합니다. 삭제 확인 창의 건수를 확인하세요.

칩·이미지 보조 화면

아래쪽 그룹 칩 영역을 위로 끌어 보조 화면으로 바꾸고, 아래로 끌어 일반 리스트로 돌아갑니다. 보조 화면은 구매대상과 구매완료 두 영역으로 나뉩니다. 가운데 구분선을 끌어 두 영역의 높이를 조절합니다.

쇼핑리스트 보조 화면 모드 설정에서 텍스트 칩 또는 이미지 형태를 고를 수 있습니다. 이미지 형태를 선택했더라도 쇼핑리스트의 이미지 사용이 꺼져 있으면 칩으로 표시됩니다.

  1. 구매 상태 변경: 항목을 반대쪽 영역에 끌어 놓습니다. 구매완료로 옮길 때 구매일 자동 변경 옵션도 적용됩니다.
  2. 그룹 이동: 항목을 아래쪽의 다른 그룹 칩에 끌어 놓습니다.
  3. 다른 그룹에 복사: 항목을 끄는 동안 다른 손가락으로 빈 화면도 누르고, 그 상태에서 대상 그룹에 놓습니다. 원래 그룹의 항목은 남고 대상 그룹에 사본이 생깁니다.
  4. 여러 항목 함께 끌기: 여러 손가락으로 각각 항목을 끌다가, 이동·삭제 대상에 놓지 않은 상태로 한 손가락을 떼면 아직 끌고 있는 항목 쪽으로 묶을 수 있습니다. 묶음 건수와 놓을 위치를 확인하세요.
  5. 삭제: 항목을 삭제 아이콘에 끌어 놓습니다. 개별 삭제 후 실행 취소 안내가 표시되는 동안에는 해당 동작을 되돌릴 수 있습니다.

삭제 아이콘은 위·아래 영역으로 끌어 위치를 바꿀 수 있습니다. 그룹 칩도 길게 눌러 삭제 아이콘으로 끌면 그룹 삭제를 진행할 수 있으므로, 항목을 옮길 때는 항목을 잡았는지 확인하세요.

요약과 표시 옵션

쇼핑 화면의 요약에서는 항목 건수와 가격 합계, 구매 완료 건수와 금액을 확인합니다. 합계는 항목의 가격칸 값을 더하므로, 구매 비용을 비교하려면 각 가격칸에 전체 금액을 입력하세요.

쇼핑리스트 그룹 칩 한 줄 표시를 켜면 일반 리스트 아래의 그룹들이 가로 한 줄에 표시됩니다. 좌우로 스크롤해 다른 그룹을 고릅니다. 끄면 여러 줄로 표시할 수 있습니다.

구매한 물건을 관리대상으로 등록하기

  1. 쇼핑 항목을 오른쪽으로 밀거나, 기존 항목 편집 화면의 관리대상에 등록을 선택합니다.
  2. 등록할 분류, 구매일, 만료일과 알림을 확인합니다. 분류가 없다면 먼저 분류 설정에서 만듭니다.
  3. 확정하면 메인 목록에 새 관리 항목이 생깁니다. 이미지도 함께 전달됩니다.

메인 목록에서 보냈던 물건은 원래 분류가 초기 선택될 수 있습니다. 선택된 분류가 적절한지 확인하세요. 등록 후에도 쇼핑 항목이 자동으로 없어지는 것은 아니므로 계속 보관하거나 별도로 정리합니다.

11. 구매 내역

기록을 남기는 방법

쇼핑 리스트에서 항목을 선택해 구매내역에 저장하거나, 스마트 등록 결과를 구매내역에 저장합니다. 구매 내역 화면의 +로 직접 추가할 수도 있습니다.

기록에는 항목명, 수량(단위), 가격, 구매일, 구매처, 메모를 입력합니다. 이 기록을 수정해도 메인 품목이나 쇼핑 항목의 값이 함께 바뀌지는 않습니다. 같은 항목을 다시 구매내역에 저장하면 별도 기록이 생길 수 있습니다.

쇼핑 리스트의 ‘구매내역에 저장’은 저장한 오늘 날짜를 기록의 구매일로 사용합니다. 과거 구매분을 정리하는 경우 구매내역에서 날짜를 수정하거나 직접 등록하면서 원하는 구매일을 지정하세요.

조회·검색·수정

기록은 날짜별로 구분해서 보여 줍니다. 아래로 스크롤하면 다음 기록을 이어서 불러옵니다. 검색창에 항목명 또는 구매처를 입력해 찾고, 기록을 눌러 수정합니다. 자동저장은 환경설정에서 구매내역을 대상으로 지정했을 때 기존 기록 편집에 적용됩니다.

기록 정리

전체선택·선택 해제와 선택 삭제를 사용할 수 있습니다. 오래된 기록은 특정일 이전 자료 삭제에서 기준일을 고르고 삭제합니다. 이 작업은 기준일 이전의 자료를 대상으로 하므로 현재 검색 결과만 정리하려면 선택 삭제를 사용하세요.

기록을 오래 보관하려면 삭제 전에 전체 백업을 만들어 두세요.

12. 스마트 등록과 AI 설정

AI API 키 준비하기

환경설정 → 스마트 기능 및 위젯 → AI API 키 등록

  1. 사용할 제공자(ChatGPT, Gemini, Claude)의 API 키를 입력하고 저장합니다.
  2. 실제로 사용할 제공자를 기본 AI로 사용으로 선택합니다.
  3. 연결 테스트로 키와 요청 설정이 동작하는지 확인합니다.

키가 등록되면 메인 메뉴에서 스마트 등록을 사용할 수 있습니다. 분석을 실행할 때는 기본 AI와 해당 키가 모두 필요합니다. 제공자별 키는 수정·삭제할 수 있습니다. API 키는 전체 백업에 포함되지 않으므로 새 기기에서는 다시 등록합니다.

AI 고급 설정

제공자별 요청 설정
API Endpoint요청을 보낼 HTTPS 주소입니다. 쿼리 파라미터를 포함하지 않는 올바른 전체 주소를 사용합니다.
기본 모델요청에 사용할 모델명을 입력합니다. 해당 API 키로 사용할 수 있는 모델이어야 합니다.

영수증을 분석해 등록하기

  1. 스마트 등록에서 작업 그룹을 선택하거나 추가합니다. 영수증별로 그룹을 나누면 편리합니다.
  2. 카메라 또는 갤러리에서 영수증을 선택하고 구매 내역 부분을 중심으로 자릅니다.
  3. 전송 안내를 확인하고 분석을 실행합니다. 이미지에서 추출한 텍스트가 AI 서버로 전송됩니다.
  4. 분석이 끝나면 모델명, 소요 시간, 인식 건수, 인식된 구매일을 확인합니다.
  5. 각 항목을 열어 이름·분류·수량·가격·날짜를 검토합니다. AI 결과는 오인식할 수 있으므로 실제 영수증과 대조하세요.
  6. 필요한 항목을 선택해 관리대상에 등록합니다. 등록 후 이미지와 항목을 초기화할지 확인합니다.

항목명 아래 붉은 물결선은 등록에 필요한 정보가 부족함을 뜻합니다. 분류·항목명·구매일·만료일 등을 채우고, 날짜 논리 체크를 사용한다면 날짜 순서도 확인하세요. 분석 결과가 생긴 것만으로 메인 목록에 등록되지는 않습니다.

인식 결과 검토 도구

  • 이미지와 목록의 높이 조절: 경계선을 끌어 영수증 또는 추출 목록을 넓게 봅니다.
  • 인식 영역 표시: 하이라이트와 항목 포커스를 이용해 어떤 줄에서 추출했는지 확인합니다. 인식 박스는 실제 위치와 차이가 날 수 있습니다.
  • 항목 편집: 각 항목을 확인하고 이전·다음 항목으로 이동하며 보완합니다. 편집 화면의 더보기 메뉴에서 저장 후 다음으로 이동을 켜면 저장 후 다음 항목을 이어서 확인할 수 있습니다.
  • 구매일 변경(일괄): 같은 영수증의 날짜를 한 번에 맞춥니다.
  • 구매내역에 저장(일괄): 구매일과 구매처를 확인해 기록을 남깁니다. 관리대상 등록과 별도 작업입니다.

작업 그룹과 분석 중 화면 이동

그룹별로 이미지와 인식 항목을 관리하고 그룹명을 바꾸거나 그룹을 삭제할 수 있습니다. 다른 그룹의 분석을 별도로 진행할 수 있으며, 응답을 기다리는 동안 앱의 다른 화면에서 작업할 수 있습니다. 진행 중인 작업이 있으면 메뉴의 스마트 등록에 진행 표시가 나타납니다. 결과와 오류는 해당 그룹에서 확인합니다.

기존 결과가 있는 그룹에 새 이미지를 가져오면 덮어쓰기 확인이 표시됩니다. 현재 그룹 초기화는 그 그룹의 이미지와 추출 항목을 지우고, 그룹 삭제는 그룹 자체와 안의 자료를 지웁니다. 필요한 결과를 먼저 등록하거나 기록하세요.

앱 안에서 다른 화면으로 이동하는 것과 앱을 강제 종료하는 것은 다릅니다. 분석 중에는 앱을 강제 종료하지 말고, 취소가 필요하면 표시되는 취소 버튼을 사용하세요.

알림일이 의미하는 기간

만료일이 9월 19일이고 알림일이 3이면, 9월 16일부터 19일까지 알림 대상 기간입니다. 0이면 만료 당일이 대상입니다. ‘기한없음’ 항목은 제외됩니다. 여러 대상이 있으면 알림에 건수와 대표 항목이 함께 표시됩니다.

기한만료 포함을 켜면 이미 만료된 자료를 추가로 집계합니다. 이 포함 동작은 앞으로 만료될 항목의 개별 알림일 판정과 구분됩니다. 만료된 자료까지 계속 알림에 남는 것이 싫다면 옵션을 끄거나 해당 자료를 정리하세요.

배지 색과 알림은 별도입니다

‘주의·경고 배지 기준’은 화면의 상태 표시를 바꿉니다. 시스템 알림 시각이나 항목별 알림일을 변경하지는 않습니다. 알림 서비스를 꺼도 메인 목록의 날짜와 D-day 상태는 확인할 수 있습니다.

수량 0은 소비 완료를 나타내는 값입니다. 수량을 0으로 바꾸는 것만으로 날짜나 알림 설정이 지워지지는 않습니다. 소비한 물건을 보관하면서 알림을 줄이려면 항목 알림과 기한만료 포함 설정을 함께 확인하세요.

알림이 보이지 않을 때

  1. 앱의 알림 서비스와 Android의 앱 알림 허용 상태를 확인합니다.
  2. 현재 날짜가 항목의 알림 기간에 들어왔는지, 항목별 알림이 켜져 있는지 확인합니다.
  3. 알림 시각과 기기의 날짜·시간이 맞는지 확인합니다.
  4. 기기의 방해금지·배터리 절약·백그라운드 실행 제한을 확인합니다. 실제 표시 시점은 기기 상태의 영향을 받을 수 있습니다.

AI로 테마 만들기

기본 AI와 API 키가 준비되어 있으면 AI를 이용한 생성을 사용할 수 있습니다. 라이트 또는 다크를 고르고, ‘차분한 초록색, 경고는 잘 보이게’처럼 원하는 분위기를 적어 생성합니다.

성공하면 새 테마 파일을 만듭니다. 현재 편집 중인 내용을 바로 덮어쓰지는 않습니다. 생성된 테마를 불러오거나 선택해 실제 화면에서 확인합니다. 요청을 취소하거나 결과 형식 오류가 발생했다면 결과 안내를 확인하고 다시 시도합니다.

  2. 알림온나의 2주 보기 위젯을 홈 화면에 배치합니다.
  3. 위젯 설정에서 색상과 투명도를 정하고 저장합니다. 홈 화면에서 지원하는 경우 크기를 조절합니다.

위젯은 현재 주부터 2주 동안의 항목을 만료일 기준으로 보여 줍니다. 앱 안 달력의 구매일 보기와는 구분됩니다. 시작 요일과 영어 요일 사용은 앱의 달력 설정을 따릅니다.

위젯을 눌렀을 때의 동작

환경설정 → 스마트 기능 및 위젯 → 위젯 터치 시 액션

위젯 색상과 투명도

배경 색상·배경 투명도, 평일·토요일·일요일 헤더 색상, 날짜 색상, 항목 텍스트 색상, 개수 텍스트 색상, 구분선 색상, 오늘 테두리 색상을 지정할 수 있습니다.

색상 선택 창에서는 팔레트와 그라데이션 단계, 투명도를 조절하고 완전 투명 또는 불투명을 선택합니다. 설정은 위젯별로 저장할 수 있어 여러 위젯을 서로 다르게 꾸밀 수 있습니다. 배경을 투명하게 하면 홈 배경화면 위에서 글자가 잘 보이는지 확인하세요.

18. 백업과 복원

백업과 동기화의 차이

환경설정 → 데이터 관리 → 구글드라이브 백업/복원

백업은 실행한 시점의 앱 데이터를 파일로 보관하는 기능입니다. 품목·분류·태그·쇼핑·구매내역과 앱이 관리하는 이미지·테마 등을 복원하기 위한 자료를 만듭니다. 백업 이후에 수정한 내용이 기존 백업 파일에 자동 반영되지는 않습니다.

복원은 현재 데이터를 선택한 백업 시점으로 되돌립니다. 현재 항목에 백업 항목을 덧붙이는 기능이 아닙니다. 현재 자료도 필요하다면 복원 전에 별도 이름으로 백업해 두세요.

Google Drive에 백업하기

  1. Google 계정 연결을 누르고 사용할 계정으로 연결합니다.
  2. 백업 및 복원 시 환경설정 포함 여부를 정합니다.
  3. 데이터 백업을 누르고 파일명을 입력합니다. 날짜나 기기명을 포함하면 나중에 구분하기 쉽습니다.
  4. 시작한 뒤 업로드가 끝날 때까지 기다리고 완료 메시지를 확인합니다.

같은 이름을 반복 사용하면 기존 파일이 갱신될 수 있습니다. 여러 시점의 백업을 남기려면 알림온나_20260912처럼 이름을 구분하세요. 계정 연결을 해제하는 것은 앱 데이터나 Drive의 백업 파일을 삭제하는 작업이 아닙니다.

환경설정 포함, 병합, 치환

환경설정 복원 옵션
환경설정 포함 꺼짐복원 시 현재 환경설정 값을 유지합니다. 데이터는 선택한 백업의 내용으로 복원됩니다.
환경설정 포함 + 병합백업에 있는 설정값을 적용하고, 백업에 없는 설정은 현재 값을 유지합니다.
환경설정 포함 + 치환복원 대상 설정을 먼저 비운 뒤 백업 값을 적용합니다. 백업에 없는 설정은 기본값으로 돌아갈 수 있습니다.

‘병합’은 환경설정에 대한 설명입니다. 현재 품목과 백업 품목을 합친다는 뜻이 아닙니다. 백업에 환경설정이 포함되어 있는지도 함께 확인하세요.

백업에서 복원하기

  1. 백업을 만든 Google 계정으로 연결합니다.
  2. 환경설정 포함 여부와 복원 방식을 정하고 데이터 복원을 누릅니다.
  3. 목록에서 파일을 고릅니다. 파일명과 복원 옵션을 확인한 뒤 복원 시작을 누릅니다.
  4. 다운로드와 복원이 끝나면 메인 목록, 쇼핑, 구매내역, 이미지, 설정, 위젯을 확인합니다.

데이터 복원(파일 선택) 메뉴가 표시되는 환경에서는 기기에 보관한 앱 백업 파일을 직접 선택할 수도 있습니다. 파일 복원도 같은 데이터 교체와 환경설정 정책을 따릅니다.

파일 선택이나 다운로드를 취소해 복원 적용 단계에 들어가지 않았다면 기존 자료를 그대로 사용합니다. 실제 복원을 시작할 때는 복원 전 상태를 보관한 안전 백업을 만들고, 적용에 실패하면 원래 자료로 되돌리는 처리를 수행합니다. 복원 실패 메시지의 안내를 확인하세요.

새 기기로 옮길 때 확인할 것

  • 예전 기기에서 가장 최근 자료를 백업했는지 확인합니다.
  • 새 기기에서 같은 Google 계정의 백업을 선택하고 복원합니다.
  • AI API 키는 백업에 포함되지 않습니다. 필요한 키를 새 기기에 다시 등록합니다.
  • Google 계정 연결과 시스템 알림 권한은 새 기기에서 다시 확인합니다.
  • 홈 화면 위젯의 배치는 새 기기의 홈 화면에서 직접 추가합니다.

19. 엑셀과 구버전 데이터

엑셀 내보내기

환경설정 → 데이터 관리 → 메일로 엑셀파일 내보내기를 실행하면 메인 품목을 .xlsx 파일로 만들고 공유 화면을 엽니다. 메일 등 원하는 공유 대상을 선택합니다.

열은 카테고리, 항목명, 수량, 가격, 구매일, 만료일, 메모, 등록일입니다. 엑셀로 목록을 확인하거나 자료를 가공할 때 사용합니다.

엑셀은 앱 전체 백업이 아닙니다. 이미지, 태그 연결, 개별 알림, 쇼핑리스트, 구매내역, 테마·설정을 원래 상태 그대로 복원하는 용도가 아닙니다. 전체 보관과 기기 이전에는 백업/복원을 사용하세요.

가져올 파일 작성 규칙

.xlsx의 첫 번째 시트를 읽으며 첫 번째 행은 열 이름이어야 합니다. 제목 행을 따로 넣거나 앞에 빈 시트를 두지 마세요. 열 순서는 달라도 되지만 지원하는 열 이름을 사용합니다.

엑셀 가져오기 열 이름과 예시
항목명 · 필수항목명, 항목, Item Name, Name. 각 데이터 행에 이름이 있어야 합니다.
구매일 · 필수구매일, 등록일, 시작일, Buy Date, Purchase Date.
만료일 · 필수만료일, 소비기한, 유통기한, Expiry Date, Expiration Date.
분류 · 선택분류, 그룹, 카테고리, Category, Group. 여기의 그룹 열은 메인 분류로 가져옵니다.
수량 · 선택수량, Quantity, Qty.
가격 · 선택가격, 금액, Price, Amount. 0 이상 100억 미만의 숫자입니다. 12.5처럼 소수 가격도 읽습니다.
메모 · 선택메모, 비고, Memo, Note.

날짜는 20260912처럼 YYYYMMDD를 텍스트로 작성하면 해석이 명확합니다. 260912는 2026년으로 해석하며 2026-09-12도 사용할 수 있습니다. 엑셀 가져오기는 앱 화면의 날짜 표시 순서와 같은 방식으로 모든 형식을 해석하는 것은 아니므로, 연·월·일 순서의 명확한 값으로 준비하세요.

첫 행: 분류 | 항목명 | 수량 | 가격 | 구매일 | 만료일 | 메모
데이터 예: 냉장식품 | 우유 | 2 | 4500 | 20260912 | 20260919 | 냉장보관

가져올 때 분류명은 최대 20자, 항목명은 30자, 수량은 20자로 제한되어 긴 값이 잘릴 수 있습니다. 불필요한 빈 데이터 행을 지우고 실제 달력에 있는 날짜인지 확인하세요.

미리보기 후 실제 데이터로 저장

  1. 환경설정 → 데이터 관리 → 데이터 가져오기에서 엑셀 파일을 선택합니다.
  2. 분석이 끝나면 분류별 건수와 항목별 이름·날짜·메모를 확인합니다.
  3. 실제 데이터로 저장을 실행합니다. 같은 이름의 분류가 있으면 그 분류에 추가된다는 안내를 확인합니다.
  4. 저장 완료 후 메인 목록에서 자료를 확인하고, 필요한 태그·이미지·알림 등을 보완합니다.

엑셀 가져오기는 기존 품목에 새 자료를 추가합니다. 같은 파일을 다시 저장하면 중복 항목이 생길 수 있습니다. 현재 가져오기에서는 새 항목의 알림을 사용·3일 전으로 등록하므로, 가져온 뒤 용도에 맞게 확인하세요.

분석 실패 시 표시된 행과 오류 내용을 수정하고 파일을 다시 선택합니다. 이전에 성공한 미리보기가 화면에 남아 보일 수 있지만 실패한 가져오기의 저장 가능한 결과를 뜻하지는 않습니다. 새 분석의 성공을 확인한 다음 저장하세요.

구버전 백업 마이그레이션

환경설정 → 데이터 관리 → 구버전 백업 마이그레이션은 이전 ‘유통기한 관리(Best Before Manager)’ 앱의 백업을 현재 형식으로 변환합니다. 일반 엑셀 가져오기나 현재 앱의 백업 복원과 구분해서 사용합니다.

  1. 현재 자료가 있다면 먼저 백업합니다.
  2. 구버전 백업 파일을 선택하고 분석합니다.
  3. 분류, 항목, 태그, 쇼핑리스트, 구매내역, 항목 이미지, 이미지 보관함의 건수 요약을 확인합니다.
  4. 백업 가져오기를 실행하고 현재 자료가 교체된다는 안내를 확인합니다.
  5. 완료 후 주요 항목, 이미지, 날짜를 확인합니다. 두 앱의 자료 구조 차이로 일부 정보는 그대로 옮겨지지 않을 수 있습니다.

프로그램 정보에서 확인하는 내용

환경설정 → 앱 정보 및 시스템 → 프로그램 정보

  • 앱 버전과 빌드: 설치된 버전을 확인합니다. 문제가 있을 때 어떤 버전에서 발생했는지 기록할 수 있습니다.
  • 개인정보처리방침: 링크에서 앱의 개인정보 처리 안내를 확인합니다.
  • 사용 매뉴얼: 현재 설명서를 엽니다.
  • 오픈소스 라이브러리: 사용한 패키지의 출처, 저작권, 라이선스를 확인합니다.
  • 포함된 폰트: 앱에 포함된 글꼴 정보를 확인합니다.

기기 저장과 외부 서비스

알림온나는 기기에 저장된 데이터를 기반으로 동작합니다. 메인 품목, 쇼핑 리스트, 구매 내역, 등록한 이미지 등의 자료는 기기 안에 보관하며, 일반적인 조회·등록·편집은 이 자료를 사용합니다.

외부 서비스와 연결하는 기능을 사용할 때는 해당 작업에 필요한 자료가 전달됩니다. 예를 들어 Google Drive 백업에는 백업 파일이, 스마트 등록의 AI 분석에는 영수증에서 인식한 텍스트가 사용됩니다. 어떤 기능에서 무엇을 전달하는지는 아래에서 구분해 안내합니다.

영수증 이미지는 어떻게 분석하나요?

스마트 등록의 AI 분석 과정에서 영수증 이미지 자체는 외부 AI 서비스로 전송하지 않습니다. 사진에서 글자를 읽는 작업과 읽은 글자를 구매 정보로 정리하는 작업을 다음과 같이 나누어 처리합니다.

  1. 기기 안에서 글자 읽기: 선택하거나 촬영한 영수증 이미지를 기기 내부의 OCR 엔진으로 처리합니다. OCR은 사진 속 글자를 텍스트로 바꾸는 기능이며, 알림온나는 온디바이스 방식의 Google ML Kit를 사용합니다.
  2. 텍스트로 AI 분석 요청: OCR로 인식한 텍스트에 줄 번호와 분석 지시를 붙여, 설정한 AI 서비스에 전달합니다. AI가 구매일·품목명·수량·가격을 정리할 수 있도록 하는 요청이며, 이미지 파일은 이 요청에 포함하지 않습니다.
  3. 결과 확인 후 저장: AI가 돌려준 구매 정보를 앱에서 미리보기로 보여줍니다. 인식 결과를 확인하고 필요한 값을 수정한 다음 실제 항목으로 저장합니다.

전송되는 텍스트의 범위: OCR 결과에는 구매 품목 외에도 영수증에 적힌 주소·전화번호·결제 관련 문구가 포함될 수 있습니다. 분석 전에 이미지 자르기로 필요한 구매 내역 부분을 선택하면 외부에 전달되는 텍스트의 범위를 줄일 수 있습니다. 직접 입력 기능으로도 품목을 등록할 수 있습니다.

AI 서비스에 전달하는 정보의 범위

AI 요청은 해당 기능을 처리하는 데 필요한 최소 범위의 입력 내용과 처리 지시로 구성합니다. 저장된 전체 품목 목록이나 구매 내역, 이미지 저장소의 사진을 AI 요청에 함께 첨부하지 않습니다. 기능별로 사용하는 입력은 다음과 같습니다.

오류 보고의 목적과 전송 선택

앱의 비정상 종료 등 문제의 원인을 파악하고 안정성을 개선하기 위해 Firebase Crashlytics를 통한 오류 보고를 사용할 수 있습니다. 보고에는 오류 내용과 발생 위치를 나타내는 실행 기록, 앱 버전과 기기·운영체제 정보 등 문제 분석을 위한 진단 정보가 사용됩니다.

오류 보고의 자동 전송은 기본적으로 꺼져 있습니다. 보고 대상 오류가 발생하면 진단 정보를 기기에 기록해 두고, 다음 앱 실행 시 이전 오류가 확인되면 ‘오류 보고 알림’에서 전송 여부를 묻습니다.

  • 동의 및 전송: 기기에 보관된 미전송 오류 보고를 Firebase로 전송하여 오류 수정과 앱 개선에 활용할 수 있도록 합니다. 이 선택은 전송을 기다리는 오류 보고에 적용되며, 이후 오류의 자동 전송을 켜는 설정은 아닙니다.
  • 닫기: 전송을 거부합니다. 전송을 기다리던 오류 보고를 기기에서 삭제하고 외부로 보내지 않습니다. 이때 삭제하는 것은 오류 보고이며, 등록한 품목이나 이미지 등의 앱 데이터는 유지됩니다.

오류 보고 전송은 선택 사항입니다. 거부해도 앱의 일반 기능은 계속 이용할 수 있습니다.

앱 삭제나 기기의 앱 데이터 지우기는 기기에 저장된 자료를 잃게 할 수 있습니다. 앱을 옮기거나 초기화하기 전에 복원에 사용할 백업이 있는지 확인하세요.
